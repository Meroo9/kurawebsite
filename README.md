# كورا للأبحاث والتعليم الطبي — KURA Research

منصة عربية RTL للحسابات والكورسات والمحاضرات والطلبات البحثية والمنشورات، بصلاحيات منفصلة للمدير والموظف وطالب كورا والزائر المسجل.

## دليل المستخدم

- [الدليل العربي الكامل](docs/USER_GUIDE_AR.md): خطوات عملية لكل دور.
- داخل التطبيق: `/guide`، مع تصفية حسب الدور والبحث وطباعة الدليل كاملًا وحفظه PDF من نافذة طباعة المتصفح.
- نسخة نصية قابلة للتنزيل: `/docs/kura-user-guide-ar.md`.
- المصدر الموحد: `frontend/src/content/user-guide.ar.json`.
- بعد تعديل المصدر، أعد توليد النسختين النصيتين بالأمر `node scripts/build_user_guide.cjs` ثم تحقق من صفحة الدليل.

## الوظائف المنفذة

- حسابات بالبريد وكلمة المرور، ملف شخصي وصورة، استعادة الحساب، اعتماد KRC يدويًا وحظر وتعطيل الحسابات.
- إدارة التصنيفات والكورسات والمحاضرات، شراء الكورس كاملًا بإيصال خارجي ومراجعة الإدارة، وصول محمي للمواد.
- طلب بحثي وعرض سعر خاص، خصم 15% للطالب المعتمد، قبول العرض ثم استلام حصري لموظف دون اشتراط الدفع مقدمًا.
- ملفات خاصة، نتائج محجوبة حتى اعتماد السداد الكامل، دفعات جزئية وإيصالات، جولة تعديل واحدة وإكمال وإلغاء مع مراجعة عند الحاجة.
- منشورات الإدارة بصور، مسودات ونشر، إعجاب وتعليقات وإشراف؛ لا تظهر الصور علنًا إلا للمنشورات المنشورة.
- سجلات المدفوعات والعمليات، وصفحات ملائمة للهاتف واللوحي والحاسوب.

الاشتراكات الشهرية والإعلانات المجدولة غير مفعلة. لا توجد بوابة لتحريك أموال أو استرداد مالي آلي.

## بنية المشروع

| المسار | المحتوى |
|---|---|
| `frontend/` | React، التوجيه، الواجهة العربية ومكونات shadcn |
| `backend/` | FastAPI والصلاحيات والمنطق وقاعدة MongoDB |
| `backend/tests/` و`tests/` | الاختبارات الوظيفية واختبارات المتصفح |
| `docs/` | دليل المستخدم القابل للقراءة مع الكود |
| `scripts/` | أدوات التوثيق والإدارة المصرح بها |
| `memory/PRD.md` | نطاق المنتج والقرارات وسجل التغييرات |

## ملاحظات التشغيل والصيانة

- تُقرأ اتصالات MongoDB وعنوان الواجهة ومفاتيح الخدمات من إعدادات البيئة الآمنة، ولا يتضمن المستودع قيمها. لا تُدرج أسرارًا أو روابط تفعيل أو ملفات بيانات خاصة في الكود أو الوثائق.
- يستخدم العميل `REACT_APP_BACKEND_URL` للطلبات. يحتاج الخادم إلى `MONGO_URL`, `DB_NAME`, `APP_ORIGIN`؛ ويستخدم التخزين والبريد مفاتيح التكامل المُدارة الموجودة في البيئة.
- لا توجد بيانات دخول مدير افتراضية. رابط تفعيل المالك خاص، مؤقت، ولمرة واحدة، ولا يُنشر ضمن الدليل.
- لا تُشغّل أدوات إنشاء دعوة مالك أو أدوات الاختبارات التي تغيّر البيانات دون فهم نطاقها. يجب حصر الاختبارات في حسابات مؤقتة وإعادة الإعدادات الأصلية وتنظيف بيانات الاختبار بمعرفاتها الدقيقة.
- بناء الواجهة: من مجلد `frontend` شغّل `yarn build`. توليد الدليل لا يحتاج قاعدة بيانات أو مفاتيح خدمات.
- نسخ الكود إلى GitHub لا ينسخ قاعدة البيانات أو إعدادات الخدمات، ولا يعني نشر الموقع للمستخدمين.
- بعد استكمال التعديلات، يستخدم صاحب المشروع **Save → Save to Github** لحفظها في المستودع والفرع المطلوبين. لا يدّعي هذا الملف أن عملية الرفع نُفذت بالفعل.

## الخصوصية والحدود

تُراجع صلاحيات الملفات في الخادم؛ الموظف لا يرى المدفوعات أو التسويات الخاصة. تقتصر المرفقات البحثية على بيانات منزوعة الهوية. حذف ملف من الواجهة يوقف الوصول إليه لكنه لا يضمن المحو الفعلي من التخزين المتاح. لا يوجد ادعاء بمنع نسخ الملفات المنزلة أو بضمان امتثال صحي خاص.

آخر تعليمات صاحب المشروع: **عدم نشر الموقع** ما لم يطلب ذلك لاحقًا صراحة.
