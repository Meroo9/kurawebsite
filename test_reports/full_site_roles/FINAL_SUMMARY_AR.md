# تقرير اختبار كورا الشامل

**التاريخ: 8 نوفمبر 2026 — لم يُنشر الموقع.**

## الخلاصة

اكتمل اختبار جميع أنواع المستخدمين والميزات المنفذة باستخدام حسابات مؤقتة وملفات فعلية. عولجت مشكلات الجولة الشاملة وأعيد التحقق منها بواسطة أداة الاختبار. لا توجد مشكلات تطبيق متبقية ضمن الحالات المختبرة.

## التغطية حسب الدور

| الدور | التجربة والصلاحيات التي جرى التحقق منها | الحالة النهائية |
|---|---|---|
| الزائر دون حساب | الصفحات العامة والبحث والتنقل، منع الملفات والعمليات الخاصة، طلب التسجيل عند الشراء أو التعليق | ناجح ضمن التغطية |
| الزائر المسجل | التسجيل والصورة والملف الشخصي، شراء الكورس والإيصالات، الطلب البحثي دون خصم، التفاعل والتعليقات | ناجح ضمن التغطية |
| الطالب بانتظار KRC | تسجيل فعلي بتاريخ مكتوب أو تقويم، بقاء صلاحيات الزائر، منع مجانية الطالب قبل الاعتماد | ناجح؛ أُكمل التحقق بالجولة السادسة |
| الطالب المعتمد | المجانية للكورسات المحددة فقط، خصم 15% للأبحاث فقط، المكتبة والمدفوعات والتعديل والتسليم | ناجح ضمن التغطية |
| الموظفان | استلام حصري متزامن، الملفات بعد الاستلام، العودة وإعادة الإسناد وسحب الوصول، منع الهوية والمدفوعات وملاحظات التسوية | ناجح ضمن التغطية |
| المدير | إدارة المستخدمين والموظفين والكورسات والمحاضرات والتصنيفات، مراجعة السداد، عروض الأبحاث، المنشورات والإشراف | ناجح بعد إصلاح نتيجة الحذف |
| المحظور والمعطّل | رسائل واضحة، إبطال الجلسات ومنع العمليات والملفات الخاصة، استمرار التصفح العام | ناجح ضمن التغطية |

## الرحلات المختبرة

- تسجيل ودخول وخروج وتحديث صورة وبيانات، ومنع تكرار البريد والهاتف وKRC والتصعيد الذاتي للصلاحيات.
- طلب شراء كورس كامل، انتظار المراجعة، رفض مسبب، رفع بديل، اعتماد وفتح جميع محاضرات الكورس، تنزيل ومعاينة محمية.
- طلب بحثي ومسودة واستعادة بعد فشل رفع، عرض سعر ونطاق ومدة وخصم، رفض عرض وإعادة تقديمه وقبوله.
- عمل الموظف دون اشتراط السداد؛ رفع النتائج وحجبها قبل السداد الكامل، دفعات جزئية وكاملة وإيصالات وتاريخ مراجعة.
- جولة تعديل واحدة وتسليم وإكمال؛ إلغاء قبل العمل أو قرار الإدارة بعده مع الحفاظ على تاريخ السداد.
- منشور بصورة أو دونها، مسودة ونشر وتعديل وإزالة صورة وحذف، إعجاب متكرر آمن، تعليق وحذف الكاتب أو المدير، بحث وترقيم ومشاركة رابط.
- محاولات الوصول المباشر غير المصرح، ملفات خاطئة أو كبيرة، طلبات متكررة ومتزامنة، ونصوص تبقى نصوصًا بدل تنفيذها.
- فحص الهاتف واللوحي والحاسوب بعروض 390 و1000 و1920، مع عناوين عربية وأسماء ملفات طويلة.

## الإصلاحات المؤكدة

1. العنوان الطويل في تفاصيل الكورس ومسار التنقل والبطاقات يلتف كاملًا دون إخراج المحتوى أو لوحة الشراء خارج الشاشة.
2. حذف كورس أو محاضرة غير موجودة، أو محذوفة سابقًا، يعيد رسالة 404 واضحة ولا يسجل حذفًا ناجحًا وهميًا.
3. رابط الملف الشخصي في الشريط الجانبي ورابط الرأس لهما معرفا اختبار مختلفان، وكلاهما يعمل ويحفظ البيانات.
4. التعثر السابق لتسجيل الطالب لم يتكرر؛ اكتمل الإرسال الفعلي مع الصورة والتقويم والاعتماد والدخول مجددًا، دون افتراض عطل في الخادم أو تغيير Auth دون دليل.

## الحفاظ على البيانات

أُزيلت الحسابات والبيانات المؤقتة فقط بمعرفاتها، وتحققت مطابقة الإعدادات والكورسات ودعوة المدير الأصلية لحالتها قبل الاختبار. لم يُستهلك رابط المالك ولم تُجرَ عملية نشر. التخزين لا يتيح محو الأجسام ماديًا؛ أزيلت مراجع ملفات الاختبار بحيث توقف الوصول إليها.

## ما لم يشمله الاختبار

- أجهزة فعلية، اختبار ضغط أو فيديوهات بحجم 100MB أو جودة الشبكة والصوت.
- تأكيد ظهور رسالة الاستعادة في علبة بريد شخصية وفتح رابطها؛ تحقق قبول مزود البريد والإجراءات الداخلية للاستعادة فقط.
- تغيير العملة العام في الجولة الشاملة، حفاظًا على محتوى موجود؛ استُخدمت بيانات معزولة لفحص تاريخ الأسعار وفصل العملات.
- تفعيل دعوة المالك الأصلية، تدقيق أمني تخصصي، أو نشر الموقع.
- الاشتراكات الشهرية والإعلانات المجدولة لأنها غير مفعلة حاليًا.

**نقطة التوقف:** يبقى الموقع دون نشر وفق طلب المستخدم؛ لا يُفهم هذا التقرير على أنه إذن بالنشر.
